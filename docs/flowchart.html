SCRATCH-E2E pipeline flow

Eight standalone SCRATCH pipelines merged into one DAG. A backbone carries a Seurat object from FASTQ through annotation and CNV calling to an explicit malignant / non-malignant split; the tumour compartment goes to metaprograms, the microenvironment to batch correction and the three analyses that follow it. An integration layer joins every stage's per-cell result back onto one master object and renders a single report.

Applied to the microenvironment only. Correcting batch across a mixed object would regress out genuine tumour heterogeneity along with the batch effect, which is why this sits on the non-malignant arm rather than on the backbone. Its own exclude_labels subsetting is now empty by default, since STRATIFY has already removed malignant cells and filtering twice would drop cells on a lineage proxy.

CNV backbone · stage 5 Four callers available; their per-cell verdicts drive the split.
expression-based · parallel INFERCNV continuous CNV load SCEVAN tumour / normal class COPYKAT_PROCESS aneuploid / diploid + allele-aware · opt-in NUMBAT_PREP → NUMBAT_PILEUP → NUMBAT_RUN --run_numbat true · needs BAM + phasing panel
inannotated object · possorted_genome_bam.bam (Numbat)
out*_infercnv_meta_object.RDS · *_scevan_meta_object.RDS · *_numbat_calls.tsv

The first three infer copy number from expression smoothed along the genome, so they are structurally blind to copy-neutral LOH — allele ratios change, dosage does not, and no expression signal is produced. Numbat reads phased heterozygous SNPs from the BAM and sees it. It is not a better-tuned version of the others; it measures a channel they cannot.

Numbat is split into three processes so the expensive pileup caches independently of the model fit. NUMBAT_PREP exists because the BAM speaks raw cellranger barcodes while the merged object does not — it writes an explicit barcode → cell_id map rather than guessing with a regex, and builds counts from post-QC cells so already-discarded droplets are not modelled.

STRATIFY backbone · stage 6 · new The pivot: assigns every cell to a compartment.
STRATIFY_COMPARTMENTS → consensus over the callers that ran → lineage gate (override) → writes malignant_status malignant → tumour object non_malignant → microenvironment object ambiguous → neither, by default
inannotated object + every CNV caller that ran
out*_malignant_object.RDS · *_nonmalignant_object.RDS · assignment.csv · cnv_false_positive_by_lineage.csv

Cell type defines the compartment; CNV adjudicates within it. Immune, stromal and endothelial lineages are non-malignant regardless of their CNV score. Without that gate the procedure is internally inconsistent: those same lineages define the null distribution for inferCNV's score, yet nothing stops one of them landing above the cutoff — with a one-sided mean + 3 SD threshold a fixed fraction will, by construction, and on a large immune infiltrate that is tens of cells entering the tumour compartment.

The gate is a negative list, not a positive one. Unlabelled and Unknown cells are left to the CNV evidence — which is what keeps a glioma's astrocyte-like cells in play, since the marker database has no glial lineage and a positive "candidate tumour" list would discard exactly the cells being looked for.

The overrides are counted into cnv_false_positive_by_lineage.csv: cells a known non-malignant lineage rescued from a malignant CNV call. That percentage is an empirical false-positive rate for the callers, and the first number to look at before trusting any tumour call.

Within the candidate compartment, CNV evidence decides and the annotation label is the fallback. Under consensus a majority verdict wins; an even split, or no verdict at all, falls to the label. ambiguous therefore means "no CNV verdict and no usable label" — not "the callers disagreed". inferCNV has no hard call, so its cutoff is set per sample from that sample's own reference lineages, because a CSF aspirate and a resection do not share a scale.

New — no equivalent existed in any of the eight source repositories. Excluding malignant cells is what makes composition comparable between patients, since tumour content otherwise dominates every proportion. Abundance is tested on per-sample proportions rather than per cell, so thousands of cells from one patient are not treated as independent observations.

Its eight optional summary inputs each carry their own placeholder file. Sharing one NO_FILE made MASTER_SUMMARY fail with an input name collision whenever more than one was absent.

MICROBIOME independent · not implemented Wired into the DAG, disabled by default.

All eight modules its subworkflow imports are absent from the source repository, and the original entry point pointed at subworkflows/ while the directory is subworkflow/ — so it could not have run there either. The BAM channel and the stage slot exist, so only the modules need writing.
